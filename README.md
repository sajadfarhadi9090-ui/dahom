# 🎓 کلاس دهم — نسخهٔ «پایتون خالص»

سایت آموزشی پایهٔ دهم که **تمام صفحات HTML داخل توابع پایتون** ساخته می‌شوند.
بدون Jinja2، بدون render_template، بدون پوشهٔ templates.

## 🚀 اجرا (ویندوز)

```
run.bat
```

یا دستی:

```bash
python -m venv venv
venv\Scripts\activate        # مک/لینوکس: source venv/bin/activate
pip install -r requirements.txt
python app.py
```

- سایت: `http://localhost:5000`
- پنل مدیریت: `http://localhost:5000/panel` — رمز پیش‌فرض: `dahom123`

## 📁 ساختار

```
dahom-pure/
├── app.py            ← تمام منطق + ساخت HTML درون پایتون
├── requirements.txt
├── run.bat / run.sh
├── render.yaml
├── static/           ← css / js / فونت وزیرمتن
└── uploads/          ← videos/ و docs/ (فایل‌های بارگذاری‌شده)
```

## ✨ امکانات

- ۳ رشته (ریاضی و فیزیک، علوم تجربی، علوم انسانی) + ۲۱ درس (مشترک و تخصصی)
- ۵ نوع مطلب: ویدیو، جزوه، گام به گام، نمونه سوال امتحانی، سوالات کتاب
- آپلود فایل یا لینک؛ دانلود خودکار از لینک (yt-dlp برای ویدیو، urllib برای اسناد) بدون نمایش آدرس مبدأ
- **ثبت‌نام و ورود دانش‌آموز** + صفحهٔ «حساب من» با تاریخچهٔ تراکنش‌ها
- **پلن‌های اشتراک** (قابل تنظیم از پنل: نام، مدت، قیمت، تخفیف) + **پرداخت با زرین‌پال** (تست/واقعی)
- **دانلود بر اساس اشتراک:** ویدیو و جزوه برای همه قابل مشاهده/پخش است؛ دانلود فقط با اشتراک فعال (یا مدیر)
- پنل مدیریت جداگانه در `/panel` (بدون لینک از سایت عمومی) + مدیریت پلن‌ها + لیست خریداران و تراکنش‌ها
- بدون نمایش تاریخ/ساعت در صفحات عمومی
- کاملاً فارسی، RTL، واکنش‌گرا، فونت وزیرمتن آفلاین

## 🔐 متغیرهای محیطی مهم

| متغیر | توضیح |
|---|---|
| `SECRET_KEY` | رشتهٔ تصادفی برای امنیت سشن |
| `ADMIN_PASSWORD` | رمز پنل مدیریت (پیش‌فرض dahom123) |
| `ZARINPAL_MERCHANT_ID` | مرچنت‌کد درگاه زرین‌پال |
| `ZARINPAL_SANDBOX` | `1` = تست ، `0` = واقعی |
| `ADMIN_PANEL_PATH` | مسیر پنل (پیش‌فرض panel) |
